# mmp Time — Implementation Plan

Spec: `docs/superpowers/specs/2026-10-08-time-design.md`. Inline execution, TDD for core logic.

1. **Pure helpers** (`src/core/time/`): `duration.ts` (parse `1h30m`…), `periods.ts`
   (period → local from/to, local day ↔ UTC minute), `blocks.ts` (minutes → blocks, split by
   local day). Unit tests.
2. **Migration 3 + settings**: `activity`, `ai_sessions`, `time_entries`, `import_state`;
   `idleMinutes`, `claudeProjectsDir`, `weekStart` in `SettingsRepository`.
3. **Importer** (`importer.ts`): streaming incremental JSONL reader (byte offsets, partial
   lines, truncation), signal/cost extraction, git commit import by author. Fixture tests +
   real-data timing.
4. **TimeRepository** (`repository.ts`): attribution by cwd, report (project/client/category/
   day, unassigned, cost spreading), blocks, manual entries CRUD. Tests.
5. **App wiring**: `app.time` with single-flight `sync()`; server background sync on start +
   5-minute interval.
6. **Interfaces**: HTTP routes, MCP tools (`time_report`, `log_time`, `sync_time`), CLI
   (`mmp time …`). Tests.
7. **Dashboard**: Time page (chart via dataviz guidance), project Time panel, client month
   totals, Settings fields.
8. README, real-data verification, review, fixes, push.
