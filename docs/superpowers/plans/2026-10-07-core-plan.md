# mmp Core — Implementation Plan

Spec: `docs/superpowers/specs/2026-10-07-core-design.md`. Execution: inline, TDD for core logic,
one commit per task.

1. **Scaffold** — `package.json` (type module, scripts: build, test, start, dev, prepare),
   `tsconfig`, `.gitignore`, `.env.example`, `LICENSE` (MIT), `bin/mmp.js`.
2. **Config** — `src/config.ts`: load `.env`, defaults, data dir; tests.
3. **Database** — `src/core/db.ts`: open SQLite (WAL, busy timeout, FKs), migrations, local
   user bootstrap, `paths.ts` (path_key); tests.
4. **Detection** — `src/core/detect/stack.ts`, `src/core/detect/git.ts`, `activity.ts`; tests
   with temp dirs and a real git repo.
5. **Repository layer** — `src/core/projects.ts`, `workspaces.ts`, `tags`, `settings.ts`,
   `resolve.ts` (ref resolution, current project by path); tests.
6. **Scanner** — `src/core/scanner.ts` reconcile logic + concurrency; tests.
7. **App facade** — `src/core/app.ts`: one object wiring db + services used by every entry point.
8. **CLI** — `src/cli/index.ts` with commander; smoke tests.
9. **HTTP server** — `src/server/*`: Fastify, host guard, JSON guard, routes, static web,
   open folder/VS Code; tests with `inject`.
10. **MCP server** — `src/mcp/index.ts`; test with in-memory transport.
11. **Dashboard** — `web/` Vue 3 + Vite + Tailwind + vue-router + vue-i18n: Projects,
    Project detail, Settings.
12. **Docs** — README (install, CLI, MCP setup for Claude Code, Laragon reverse proxy),
    CONTRIBUTING, end-to-end verification on the real `C:\laragon\www`.
